# aplicacao/front/

Interface em **React** usada pelo médico.

Fluxos principais (detalhes em `documentacao/03-casos-de-uso.md`):

1. login do médico;
2. cadastro do paciente e registro do consentimento;
3. captura das 10 digitais, dedo a dedo;
4. visualização do resultado da análise, sempre com o aviso de que se trata de
   indicação complementar, não de diagnóstico.

O código ainda não foi criado. Antes de começar, ler o `CLAUDE.md` da raiz.
