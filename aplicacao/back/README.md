# aplicacao/back/

API em **.NET (ASP.NET Core Web API)**.

Responsabilidades (detalhes em `documentacao/`):

- autenticação e cadastro de médicos;
- cadastro de pacientes e registro de consentimento;
- recebimento e armazenamento protegido das 10 digitais;
- solicitação da análise ao serviço de inferência em Python e registro do resultado;
- trilha de auditoria de acessos.

O código ainda não foi criado. Antes de começar, ler o `CLAUDE.md` da raiz e os
documentos `documentacao/02` a `06`.
